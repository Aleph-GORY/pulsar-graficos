# Flujo de manufactura por encargo
El flujo de manufactura por encargo describe los pasos que debe seguir unx artistx visual para imprimir su diseño mediante el taller.

## Relevancia y suposiciones
El flujo de compra es un flujo de segunda prioridad para pulsar, es una forma segunda fuente de ingresos para solventar los gastos del taller.

Este flujo está diseñado para funcionar con las personas del segmento B de clientes.
